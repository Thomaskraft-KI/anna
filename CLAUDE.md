# Kontext für Claude

## Was dieses Repo ist

Ablage rund um eine zweitägige KI-Schulung (01.–02.09.2026) von Thomas Kraft.
Kein Software-Projekt — es gibt keinen Code, keine Tests, keinen Build.
Der Inhalt sind Notizen, Prompts, Ideen und Begriffe in Markdown.

Alles auf Deutsch — Dateiinhalte, Commit-Messages, Antworten.

## Konventionen

- Neue Mitschrift: `notizen/VORLAGE.md` kopieren, nicht bei null anfangen.
- Prompts kommen mit **Zweck und Ergebnis** dazu — ein Prompt ohne Kontext
  ist in vier Wochen wertlos.
- Ideen in `ideen/backlog.md` bekommen einen Aufwand/Nutzen-Eintrag,
  damit man später priorisieren kann.
- Rohe Mitschriften nicht glattbügeln. Sie dürfen stichpunktartig und
  unfertig sein — das ist ihr Zweck.
