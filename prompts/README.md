# Prompt-Sammlung

Prompts, die sich in der Schulung oder im Alltag bewährt haben.

**Regel:** Ein Prompt kommt nie allein. Immer dazu: wofür er war und was
dabei herauskam. Ein Prompt ohne Kontext ist in vier Wochen wertlos.

## Format

```
### Kurzer Titel
**Wofür:** Eine Zeile — welches Problem löst das?
**Womit:** Claude / ChatGPT / sonstiges
**Prompt:**
> Der Prompt im Wortlaut.

**Ergebnis:** Hat es funktioniert? Was musste nachgeschärft werden?
```

---

## Beispiel (ersetzen, sobald der erste echte Prompt da ist)

### Kundenanfrage in Angebotstext übersetzen
**Wofür:** Aus einer knappen WhatsApp-Anfrage einen sauberen Angebotstext machen.
**Womit:** Claude
**Prompt:**
> Du bist Mitarbeiter im KS Autoglas Zentrum Elmshorn. Formuliere aus der
> folgenden Kundenanfrage einen freundlichen, kurzen Angebotstext auf Deutsch.
> Keine Preise erfinden — wo ein Preis fehlt, schreibe „[Preis eintragen]".
> Anfrage: ...

**Ergebnis:** Noch nicht getestet.
